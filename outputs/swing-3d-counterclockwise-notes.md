# 팔 굽힘 방향을 반대로 수정한 그네 GIF

파일: swing-3d-counterclockwise-motion.gif / swing-3d-counterclockwise-motion.mp4

직전 시계 방향 GIF와 팔꿈치의 굽힘 방향을 반대로 바꿨다. 같은 카메라 화면에서 손 → 팔꿈치 → 어깨의 순서는 반시계 방향을 유지하며, 그네가 뒤집혀도 팔꿈치의 굽힘 방향을 바꾸지 않는다. 양손은 허리 높이의 봉에 고정하고 위팔 0.32m, 팔꿈치부터 손잡이 중심까지 0.34m를 유지한다.

전체 화면과 확대 화면에 카메라를 적용한 뒤 손·팔꿈치·어깨의 방향을 매 프레임 확인했다. 단단한 봉·공기 및 축 저항 없음의 기존 운동 데이터를 사용했으며, θ=180° 도달 시간은 약 27.1134초다. 팔의 힘이나 관절 토크를 새로 계산한 것은 아니다. GIF는 960×540, 15fps, 약 28.67초이고 마지막 정지 자세를 포함하며 반복 재생한다.
